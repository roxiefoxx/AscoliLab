# Non-normal dynamics outputs

- `non_normal_dynamics_report.html` — primary self-contained technical report.
- `report_artifact.json` — canonical validated report input with provenance and bounded datasets.
- `summary.json` — compact machine-readable headline results.
- `tables/` — 26 CSV outputs covering descriptive statistics, strengths, non-normality, thresholds, gain, node/edge sensitivity, nulls, stochastic covariance, and robustness.
- `figures/` — 11 publication-quality PNG figures.
- `pseudospectrum_grid.npz` — finite resolvent grid used for the pseudospectral figure.
- `VALIDATION.md` — validation status, independent spot checks, and required caveats.

The complete pipeline is `../non_normal_analysis.py`; the executed reader notebook is `../non_normal_dynamics_analysis.ipynb`. The notebook is regenerated by `../build_explained_notebook.py`, which keeps each computation between an explanatory methods/terms cell and a results-interpretation cell.
